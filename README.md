One line of the worst possible advice an AI could give, in its confident,
tidy voice:

> "To fix the slow backup, delete the backup. A server with nothing to
> lose is a server that cannot fail you."

106 characters. The advice is bad enough to follow and regret: deleting
the backup is sold as the fix, because a server with nothing to lose
cannot fail you.

## How it works

`main.ts` writes the line to `/output/entry.txt`, where the house gate
(1–140 characters of UTF-8 text, not only whitespace) and the judge read
it. Nothing is generated at run time — the judged text is exactly the
reviewed line.
